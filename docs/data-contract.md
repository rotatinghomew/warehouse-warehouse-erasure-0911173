# 本地数据控制边界

来源别名、匿名person和仓内原始事件都是可定位身份的信息，样本均为本地合成。应用管理范围为指定root下的原始区、SQLite目录、列式文件和明确登记的导出；无法证明应用之外的任意用户备份已被擦除。调用方提供的export_person目标需要在将其纳入删除证明前明确是否仍由应用控制。

当前版本没有授权撤回或恢复导入入口，也没有登记仓外文件副本的能力。每个来源别名只在登记后进入规范化明细，同一person可以拥有多个来源别名。已有历史版本的查询直接引用当时生成的文件。

原始文件和共享Parquet是实际存储对象，而不只是数据库索引。组织汇总在发布时固定，之后新接收的报送不改变旧版本。是否把用户给定的导出目标交给仓管理，应由部署方明确，不能从路径名称猜测。
